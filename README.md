# IoT Smart Greenhouse

Учебная веб-платформа мониторинга и управления теплицей. Реального оборудования нет: показания генерирует программный симулятор, устройства виртуальные.

## Возможности
- 3 зоны (Томаты, Огурцы, Зелень), 6 датчиков и 6 устройств в каждой зоне
- ручной и автоматический режим, гистерезис, защита насоса при низком уровне воды
- предупреждения (внимание / критично), открываются и закрываются автоматически
- журнал событий автоматики и оператора
- аналитика: риск-балл, обнаружение скачков, рекомендации, 4 графика Chart.js
- настройки порогов, шаг симуляции, тема, сброс данных; всё хранится в localStorage

## Запуск
Откройте `index.html` в браузере. Для графиков нужен интернет (Chart.js подключается с CDN).

## Публикация на GitHub Pages
1. Создайте репозиторий и загрузите содержимое папки (файл `index.html` должен лежать в корне).
2. Settings → Pages → Source: Deploy from a branch → ветка `main`, папка `/ (root)`.
3. Через минуту сайт появится по адресу `https://<ваш-логин>.github.io/<репозиторий>/`.

## Важно
Пороги учебные и не являются агрономическими нормами. Секретные ключи и пароли MQTT в публичный репозиторий класть нельзя.
